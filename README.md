# python-journey

Curso **Python para quem faz infra** — 12 semanas, 84 dias, do zero ao serviço em produção.

Site: https://pereirawill.github.io/python-journey/

## Estrutura

- `index.html` — o curso (página única, sem dependências além de fontes).
- `semana-XX/dia-YY.py` — scripts diários (um commit por dia).
- `projetos/` — projetos de fase.

## Rodar local

```bash
python -m http.server 8000   # abre http://localhost:8000
```
