Método

Como usar este curso

Ritmo diário (~60 min)

  1. 10 min — rodar o código de ontem antes de abrir o de hoje.
  2. 30 min — conceito do dia + script de exemplo.
  3. 20 min — o exercício. Sem olhar a solução antes de tentar.

Dia sem tempo: 15 min de python -i com uma lib nova. O objetivo é não zerar.

IA como revisor, não autor

  • Escreva primeiro. Depois peça ao modelo para criticar o seu código.
  • Uma vez por semana, inverta: peça o código e explique linha a linha antes de rodar.
  • Nunca cole código que você não consegue explicar num commit.

Repo python-journey

  • Um commit por dia. A sequência no GitHub é o seu contador.
  • Estrutura: semana-01/dia-03.py. Projetos em projetos/.
  • README com o que aprendeu na semana, em 3 linhas.

Regra de ouro

  • Se um script de shell passar de 10 linhas, reescreva em Python.
  • Cada dia só usa o que foi visto antes. Se travar, o escopo diminui; a fase não estica.
  • Domingo é revisão + projeto. Sem conteúdo novo.
